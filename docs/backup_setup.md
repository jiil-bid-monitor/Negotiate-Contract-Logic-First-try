# 판단 기록 구글 드라이브 백업 켜기

입찰 공고 웹앱(`http://192.168.0.22:8765`)이 돌아가는 **192.168.0.22 PC**에서 한 번만 하면 됩니다. 15분 정도 걸립니다.

## 왜 하나요

웹앱에서 누른 참가·보류·불참, 사유, 대화는 **이 PC 안에만** 저장됩니다.
PC가 고장 나거나 포맷되면 전부 사라집니다.
백업을 켜면 저장할 때마다 구글 드라이브에도 사본이 올라갑니다.

- PC가 고장 나도 기록이 남습니다. 새 PC에서 웹앱을 켜면 드라이브에서 자동으로 되살립니다.
- 팀이 판단을 보는 곳은 **피드백 구글 시트**입니다(2026-10-21부터 — `docs/server_pc_sheet_setup.md`). 이 폴더는 복구용이라 팀에 공유하지 않아도 됩니다.
- 날짜별 사본이 30일치 남습니다. 실수로 지워도 며칠 전 상태로 되돌릴 수 있습니다.

## 준비물

- **백업 폴더 `입찰모니터_백업_통합`** — 폴더 주인이 자기 구글 드라이브에 만들어, 이 PC에서 로그인할 계정에 **편집자**로 공유해 둔 것.
  (뷰어로 공유되면 백업 파일을 쓰지 못합니다.)
- 이 PC에서 로그인할 **본인 구글 계정** — 위 폴더를 편집자로 공유받은 계정.
- 웹앱을 껐다 켤 수 있는 권한. 끄는 동안 1~2분은 팀원이 웹앱에 들어올 수 없으니 미리 알려 주세요.

---

## 1단계. 구글 드라이브 데스크톱 설치

이미 작업 표시줄 오른쪽 아래에 구글 드라이브 아이콘이 있으면 2단계로 넘어가세요.

1. https://www.google.com/drive/download/ 에서 **데스크톱용 Drive 다운로드**를 누릅니다.
2. 받은 파일을 실행해 설치합니다.
3. 백업 폴더를 편집자로 공유받은 본인 구글 계정으로 로그인합니다.
4. 파일 탐색기 왼쪽에 **Google Drive (G:)** 같은 드라이브가 생겼는지 확인합니다.
   - 글자가 G:가 아닐 수도 있습니다(H: 등). **그 글자를 기억해 두세요.** 아래에서 G: 대신 그 글자를 씁니다.

## 2단계. 공유받은 폴더를 '내 드라이브'에 바로가기로 추가

공유받은 폴더는 '공유 문서함'에만 있고 PC에는 내려오지 않습니다. 바로가기를 '내 드라이브'에 넣어야 PC에서 보입니다.

1. 인터넷 창에서 https://drive.google.com 을 열고, 1단계와 **같은 계정**으로 로그인되어 있는지 오른쪽 위 프로필로 확인합니다.
2. 왼쪽 메뉴에서 **공유 문서함**을 누릅니다.
3. **`입찰모니터_백업_통합`** 폴더를 찾아 **오른쪽 클릭** → **정리** → **바로가기 추가**를 누릅니다.
   - 메뉴 모양이 다르면, 폴더를 한 번 눌러 고른 뒤 위쪽 **⋮**(점 세 개) → **정리** → **바로가기 추가**.
4. 위치로 **내 드라이브**를 고르고 **추가**를 누릅니다.
5. 1~2분 뒤 파일 탐색기에서 `G:\내 드라이브\입찰모니터_백업_통합`이 보이는지 확인합니다.
   - 영문 Windows면 `G:\My Drive`입니다. 아래에서 `내 드라이브` 대신 `My Drive`를 쓰세요.
   - 안 보이면 작업 표시줄의 구글 드라이브 아이콘을 눌러 동기화가 끝났는지 확인하세요.

> **`입찰모니터_백업` 폴더(이름 끝에 `_통합`이 없는 것)는 쓰지 마세요.** 예전 화면이 쓰던 폴더라 서로 덮어씁니다.

## 3단계. 백업 폴더 위치 등록

웹앱을 **어느 창에서 켜는지**에 따라 방법이 다릅니다. 평소 서버를 켜는 창을 보고 고르세요.

- 창 제목이 `MINGW64` 이고 글자가 초록·보라색 → **깃배시(Git Bash)** → 3-A
- 창 제목이 `Windows PowerShell` 이고 `PS C:\...>` 로 시작 → **PowerShell** → 3-B

> 192.168.0.22 PC는 **깃배시**로 켭니다(2026-10-20 확인).

### 3-A. 깃배시로 켜는 경우

1. **평소 켜던 명령을 먼저 메모합니다.** 지금 서버가 돌던 깃배시 창(서버가 꺼져 있어도 됨)에 아래를 입력합니다.

   ```bash
   history | grep webapp
   ```

   나오는 줄 중 서버를 켜던 명령(`python -m webapp …` 같은 것)을 메모해 둡니다.
   서버가 아직 켜져 있으면 먼저 **Ctrl+C**로 끕니다(1~2분 동안 팀원이 못 들어오니 미리 알려 주세요).

2. 아래 한 줄을 붙여 넣고 Enter를 누릅니다. 깃배시에서 붙여넣기는 **Shift+Insert** 또는 오른쪽 클릭 → Paste입니다.
   드라이브 글자나 `내 드라이브` 이름이 다르면 그 부분만 바꾸세요.

   ```bash
   echo 'export BACKUP_DIR="G:/내 드라이브/입찰모니터_백업_통합"' >> ~/.bashrc
   ```

   - 깃배시가 새로 열릴 때마다 읽는 설정 파일(`~/.bashrc`)에 적는 것이라, **한 번만** 하면 됩니다. 두 번 하지 마세요.
   - 경로의 빗금은 `\` 가 아니라 **`/`** 입니다.

3. 깃배시 창을 **닫고 새로 엽니다.**

4. 제대로 들어갔는지 확인합니다. 방금 적은 경로가 그대로 나와야 합니다.

   ```bash
   echo $BACKUP_DIR
   ```

   아무것도 안 나오면 3번(창 새로 열기)을 했는지 확인하고, 그래도 안 나오면 2번을 다시 하세요.

### 3-B. PowerShell로 켜는 경우

1. 시작 메뉴에서 **PowerShell**을 열고, 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다.

   ```powershell
   [Environment]::SetEnvironmentVariable("BACKUP_DIR", "G:\내 드라이브\입찰모니터_백업_통합", "User")
   ```

2. 확인 — 방금 적은 경로가 그대로 나와야 합니다.

   ```powershell
   [Environment]::GetEnvironmentVariable("BACKUP_DIR", "User")
   ```

> 이 설정은 PC를 껐다 켜도 남고, 바로가기·배치 파일 등 어떤 방법으로 켜도 적용됩니다.
> 단, **이미 열려 있던 창에는 적용되지 않습니다.** 웹앱을 켤 창은 새로 열어야 합니다.

## 4단계. 웹앱 다시 켜기

1. 서버가 아직 돌고 있으면 그 창에서 **Ctrl+C**로 끕니다.
2. 3단계에서 **새로 연** 창에서 레포 폴더로 이동합니다.

   ```bash
   cd ~/Negotiate-Contract-Logic-First-try
   ```

3. 평소 켜던 명령(3-A 1번에서 메모한 것)으로 서버를 켭니다. 바로가기나 배치 파일로 켜 왔다면 그것을 실행해도 됩니다.
4. 켜질 때 나오는 글에서 이 줄을 찾습니다.

   ```
   판단 기록 백업: G:/내 드라이브/입찰모니터_백업_통합
   ```

   | 이렇게 나오면 | 뜻 |
   |---|---|
   | 위처럼 경로가 나옴 | 성공 — 5단계로 |
   | 경로 뒤에 `⚠ 폴더가 없습니다` | 드라이브 글자나 폴더 경로가 다릅니다. 파일 탐색기에서 2단계 폴더 위치를 확인하고 3단계 경로를 고치세요 |
   | `판단 기록 백업: 꺼져 있음` | 설정이 이 창에 안 들어갔습니다. **창을 닫고 새로 열어** 다시 켜세요 |

## 5단계. 확인

웹앱을 켜고 1~2분 뒤 `G:\내 드라이브\입찰모니터_백업_통합` 폴더를 열어 봅니다. 아래가 보이면 끝입니다.

```
입찰모니터_백업_통합/
├─ participation.json   ← 판단 기록 원본 사본
├─ promoted.json        ← "목록에 올리기" 한 공고
└─ 날짜별/               ← 하루 하나씩, 30일치
```

그 뒤로는 누가 웹앱에서 판단을 저장할 때마다 자동으로 갱신됩니다. 따로 할 일은 없습니다.

## 6단계. 다른 팀원에게 공유 (선택, 폴더 주인이 함)

공유는 **폴더 주인**만 할 수 있습니다. 판단 기록을 보고 싶은 팀원이 있으면 폴더 주인에게 부탁하세요.

1. 폴더 주인이 구글 드라이브 웹(drive.google.com)에서 `입찰모니터_백업_통합` 폴더를 오른쪽 클릭하고 **공유**를 누릅니다.
2. 팀원 이메일을 넣고 권한은 **뷰어**로 둡니다.
   - **편집자는 이 서버 PC에서 로그인하는 계정 하나만.** 다른 사람이 파일을 고치면 기록이 꼬일 수 있습니다.
   - 판단자 이름, 사유, 대화가 들어 있으니 회사 사람에게만 공유하세요.

## 알아 둘 것

- **이 PC의 구글 드라이브가 꺼져 있으면** 백업이 쌓이지 않습니다.
  - 웹앱의 저장은 그대로 되고, 드라이브가 다시 켜지면 다음 저장부터 올라갑니다.
  - 구글 드라이브가 PC 시작 때 자동으로 켜지는지 확인해 두세요(설치하면 기본값이 자동 시작입니다).
- **백업 파일의 주인은 이 PC에서 로그인한 계정**입니다(폴더 주인이 아님). 구글 드라이브가 그렇게 정합니다.
  - 그래서 그 계정을 지우거나, 폴더 공유가 끊기면 백업 파일이 사라질 수 있습니다. 담당자가 바뀌면 폴더 주인에게 먼저 알려 주세요.
  - 저장 용량도 이 계정에서 빠지지만, 파일이 작아서(수 MB 이하) 걱정할 정도는 아닙니다.
- **PC를 바꾸거나 포맷한 뒤**에는 새 PC에서 1~4단계를 똑같이 하면 됩니다.
  - 웹앱이 켜질 때 그 PC에 판단 기록이 없으면 드라이브 백업에서 자동으로 가져옵니다.
- **며칠 전 상태로 되돌려야 할 때**는 직접 하지 말고 담당 개발자에게 연락하세요.
  - `날짜별/` 폴더의 사본을 쓰는데, 웹앱을 끈 상태에서 파일을 바꿔야 해서입니다.
- **백업을 끄려면** 아래를 하고 웹앱을 새 창에서 다시 켜면 됩니다.
  - 깃배시: 메모장으로 `C:\Users\<사용자 이름>\.bashrc`를 열어 `export BACKUP_DIR=…` 줄을 지우고 저장
  - PowerShell:

    ```powershell
    [Environment]::SetEnvironmentVariable("BACKUP_DIR", $null, "User")
    ```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 폴더에 아무 파일도 안 생김 | 4단계 표의 줄이 어떻게 나왔는지 확인. 구글 드라이브 아이콘이 "동기화 중/완료"인지 확인 |
| 웹앱이 아예 안 켜짐 | 3단계 명령의 따옴표가 빠지지 않았는지, 깃배시는 `~/.bashrc`에 같은 줄이 두 번 들어가지 않았는지 확인. 그래도 안 되면 위 "백업을 끄려면"을 실행해 원래대로 돌린 뒤 개발자에게 연락 |
