# 판단 기록 구글 드라이브 백업 켜기

입찰 공고 웹앱(`http://192.168.0.22:8765`)이 돌아가는 **192.168.0.22 PC**에서 한 번만 하면 됩니다. 15분 정도 걸립니다.

## 왜 하나요

웹앱에서 누른 참가·보류·불참, 사유, 대화는 **이 PC 안에만** 저장됩니다.
PC가 고장 나거나 포맷되면 전부 사라집니다.
백업을 켜면 저장할 때마다 구글 드라이브에도 사본이 올라갑니다.

- PC가 고장 나도 기록이 남습니다. 새 PC에서 웹앱을 켜면 드라이브에서 자동으로 되살립니다.
- 드라이브의 `판단기록.csv`를 누르면 판단 기록이 표로 보입니다. 사무실 밖에서도, 팀원도 볼 수 있습니다.
- 날짜별 사본이 30일치 남습니다. 실수로 지워도 며칠 전 상태로 되돌릴 수 있습니다.

## 준비물

- 회사 구글 계정 로그인 정보 — 백업 폴더를 둘 계정입니다. 기존 백업과 같은 계정이면 팀원 공유가 편합니다.
- 웹앱을 껐다 켤 수 있는 권한. 끄는 동안 1~2분은 팀원이 웹앱에 들어올 수 없으니 미리 알려 주세요.

---

## 1단계. 구글 드라이브 데스크톱 설치

이미 작업 표시줄 오른쪽 아래에 구글 드라이브 아이콘이 있으면 2단계로 넘어가세요.

1. https://www.google.com/drive/download/ 에서 **데스크톱용 Drive 다운로드**를 누릅니다.
2. 받은 파일을 실행해 설치합니다.
3. 회사 구글 계정으로 로그인합니다.
4. 파일 탐색기 왼쪽에 **Google Drive (G:)** 같은 드라이브가 생겼는지 확인합니다.
   - 글자가 G:가 아닐 수도 있습니다(H: 등). **그 글자를 기억해 두세요.** 아래에서 G: 대신 그 글자를 씁니다.

## 2단계. 백업 폴더 만들기

1. 파일 탐색기에서 `G:\내 드라이브`를 엽니다.
   - 영문 Windows면 `G:\My Drive`입니다. 아래에서 `내 드라이브` 대신 `My Drive`를 쓰세요.
2. 새 폴더를 만들고 이름을 정확히 **`입찰모니터_백업_통합`**으로 짓습니다.

> **이미 있는 `입찰모니터_백업` 폴더는 쓰지 마세요.** 예전 화면이 쓰던 폴더라 서로 덮어씁니다. 꼭 새 폴더를 만드세요.

## 3단계. 백업 폴더 위치를 Windows에 등록

1. 시작 메뉴에서 **PowerShell**을 열고, 아래 한 줄을 복사해 붙여 넣은 뒤 Enter를 누릅니다.
   - 드라이브 글자나 `내 드라이브` 이름이 다르면 그 부분만 바꾸세요.

   ```powershell
   [Environment]::SetEnvironmentVariable("BACKUP_DIR", "G:\내 드라이브\입찰모니터_백업_통합", "User")
   ```

2. 제대로 들어갔는지 확인합니다. 아래를 붙여 넣으면 방금 적은 경로가 그대로 나와야 합니다.

   ```powershell
   [Environment]::GetEnvironmentVariable("BACKUP_DIR", "User")
   ```

> 이 설정은 PC를 껐다 켜도 남습니다. 웹앱을 어떤 방법으로 켜든(바로가기, 배치 파일, 직접 명령) 똑같이 적용됩니다.
> 단, **이미 열려 있던 창에는 적용되지 않습니다.** 그래서 4단계에서 웹앱을 켤 창은 새로 열어야 합니다.

## 4단계. 웹앱 다시 켜기

1. 지금 웹앱이 돌고 있는 검은 창에서 **Ctrl+C**를 눌러 끕니다(또는 창을 닫습니다).
2. **새** PowerShell 창을 열고, 평소 웹앱을 켜던 방법 그대로 다시 켭니다.
   - 바로가기나 배치 파일로 켜 왔다면, 그것을 다시 실행하면 됩니다.
3. 켜질 때 나오는 글에서 이 줄을 찾습니다.

   ```
   판단 기록 백업: G:\내 드라이브\입찰모니터_백업_통합
   ```

   | 이렇게 나오면 | 뜻 |
   |---|---|
   | 위처럼 경로가 나옴 | 성공 — 5단계로 |
   | 경로 뒤에 `⚠ 폴더가 없습니다` | 2단계 폴더 이름이나 드라이브 글자가 다릅니다. 3단계를 다시 하고 새 창에서 켜세요 |
   | `판단 기록 백업: 꺼져 있음` | 3단계 설정이 이 창에 안 들어갔습니다. **창을 새로 열고** 다시 켜세요 |

## 5단계. 확인

웹앱을 켜고 1~2분 뒤 `G:\내 드라이브\입찰모니터_백업_통합` 폴더를 열어 봅니다. 아래가 보이면 끝입니다.

```
입찰모니터_백업_통합/
├─ participation.json   ← 판단 기록 원본 사본
├─ promoted.json        ← "목록에 올리기" 한 공고
├─ 판단기록.csv          ← 표로 보는 판단 기록 (누르면 구글 시트처럼 열림)
└─ 날짜별/               ← 하루 하나씩, 30일치
```

그 뒤로는 누가 웹앱에서 판단을 저장할 때마다 자동으로 갱신됩니다. 따로 할 일은 없습니다.

## 6단계. 팀원에게 공유 (선택)

1. 구글 드라이브 웹(drive.google.com)에서 `입찰모니터_백업_통합` 폴더를 오른쪽 클릭하고 **공유**를 누릅니다.
2. 팀원 이메일을 넣고 권한은 반드시 **뷰어**로 둡니다.
   - 판단자 이름, 사유, 대화가 들어 있으니 회사 사람에게만 공유하세요.
   - 편집자로 주면 누가 파일을 고쳤을 때 기록이 꼬일 수 있습니다.

---

## 알아 둘 것

- **이 PC의 구글 드라이브가 꺼져 있으면** 백업이 쌓이지 않습니다.
  - 웹앱의 저장은 그대로 되고, 드라이브가 다시 켜지면 다음 저장부터 올라갑니다.
  - 구글 드라이브가 PC 시작 때 자동으로 켜지는지 확인해 두세요(설치하면 기본값이 자동 시작입니다).
- **PC를 바꾸거나 포맷한 뒤**에는 새 PC에서 1~4단계를 똑같이 하면 됩니다.
  - 웹앱이 켜질 때 그 PC에 판단 기록이 없으면 드라이브 백업에서 자동으로 가져옵니다.
- **며칠 전 상태로 되돌려야 할 때**는 직접 하지 말고 담당 개발자에게 연락하세요.
  - `날짜별/` 폴더의 사본을 쓰는데, 웹앱을 끈 상태에서 파일을 바꿔야 해서입니다.
- **백업을 끄려면** PowerShell에서 아래를 실행하고 웹앱을 새 창에서 다시 켜면 됩니다.

  ```powershell
  [Environment]::SetEnvironmentVariable("BACKUP_DIR", $null, "User")
  ```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 폴더에 아무 파일도 안 생김 | 4단계 표의 줄이 어떻게 나왔는지 확인. 구글 드라이브 아이콘이 "동기화 중/완료"인지 확인 |
| 웹앱이 아예 안 켜짐 | 3단계 명령의 따옴표가 빠지지 않았는지 확인. 그래도 안 되면 위 "백업을 끄려면"을 실행해 원래대로 돌린 뒤 개발자에게 연락 |
| `판단기록.csv`의 한글이 깨짐 | 드라이브 웹에서 열면 정상입니다. 엑셀로 열 때도 보통 정상이며, 깨지면 개발자에게 연락 |
