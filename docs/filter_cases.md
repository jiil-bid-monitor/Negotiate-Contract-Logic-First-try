# 필터 판단 사례 모음 — 키워드·제외 규칙 최적화용

담당자의 참가/불참 기록(웹앱 `data/webapp.sqlite3`의 states 테이블)이 쌓인 뒤,
관심·제외 키워드와 판정 규칙을 고칠 때 참고하려고 모아 둔다.
**새 사례가 나오면 아래 표에 한 줄씩 더한다** (날짜·공고·무엇이 문제였나·어떻게 정했나).

## 최적화할 때 볼 것

1. "검토 필요" 구역(관심 + 제외 키워드 공존)의 **제외 키워드별 참가/불참 비율**
   — 불참이 대부분이면 그 제외 키워드는 무조건 제외(`hardExcludeKeywords`)로, 참가가 많으면 좁히거나 뺀다.
2. 아래 **"담당자 판단에 맡김"** 사례들이 실제로 어떻게 처리됐는지 (참가/불참·사유)
   — 같은 유형이 반복해서 불참이면 그때 규칙으로 만든다.
3. 관심 키워드 하나로만 들어온 후보 중 불참이 많은 키워드 (예: "놀이터"가 건축 설계공모를 끌어오는지).
