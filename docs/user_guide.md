# 입찰 공고 탐색기 사용 안내

나라장터에 올라온 공고 중 **지일이 참가할 만한 공고를 골라** 보여주는 사내 웹페이지입니다.
공고마다 참가 조건·마감 일정·과거 실적과 얼마나 비슷한지를 카드 한 장에 정리해 줍니다.
참가 여부는 담당자가 최종 판단합니다.

---

## 1. 주요 기능

### 공고 불러오기
- **"나라장터에서 불러오기"** 버튼으로 기간을 골라 공고를 불러옵니다. 기간은 최근 7일·30일 또는 직접 지정할 수 있습니다.
- 용역·물품·공사의 **경쟁입찰 공고**와 **사전규격**을 함께 불러옵니다. 수의계약은 제외합니다.
- 불러오는 데 몇 분 걸릴 수 있습니다. 한 사람이 불러오는 중이면 다른 사람 화면에도 진행 상황이 보입니다.

### 공고 자동 선별
- 공고명에 **관심 키워드**(체험관·전시물·역사관·놀이터 등)가 있으면 후보로 올립니다.
- **제외 키워드**(유지보수·운송·설계공모 등)가 있으면 뺍니다.
- 관심 키워드와 제외 키워드가 **둘 다 있는 공고**는 버리지 않고 **"검토 필요"** 구역에 따로 모읍니다.
- 예산이 너무 작은 공고, 해외 개최 공고도 뺍니다.

### 참가 조건 자동 확인
- 공고문과 첨부파일(제안요청서 등)을 읽어 아래 내용을 확인합니다.
  - **자격**: 요구하는 면허·업종을 지일이 가지고 있는지
  - **지역**: 업체 소재지 제한이 있는지, 지일(강원특별자치도)이 해당되는지
  - **공동수급**: 공동수급 허용 여부
  - **확인 필요 요건**: 실적·현장설명회·기술인력·건축사사무소 요건이 있는지

### 마감 일정 정리
- **입찰참가자격등록 마감**을 기준으로 남은 날수(D-N)를 보여줍니다.
- 공고 게시부터 개찰까지 **일정 전체**를 한 번에 볼 수 있습니다.

### 싱크로율 (과거 실적과의 유사도)
- 공고의 과업 내용을 지일 **과거 실적 150건**과 비교해서, 가장 비슷한 실적과 얼마나 닮았는지를 %로 보여줍니다.

### 팀 공유
- 카드마다 **참가여부**(검토중·참가·보류·불참), 담당자, 대화를 남길 수 있고 팀 전체가 같이 봅니다.
- **"판단 갱신"** 버튼을 누르면 다른 팀원이 남긴 최신 기록을 받아옵니다.

## 2. 화면 구성

| 탭 | 내용 |
|---|---|
| **실제 공고** | 선별을 통과한 후보 공고. 매주 확인할 기본 목록입니다. 마감된 공고는 맨 뒤로 갑니다. |
| └ **검토 필요** | 관심 키워드와 제외 키워드가 함께 있는 공고. 실제 공고 탭 맨 아래에 있습니다. |
| **제외된 공고** | 걸러진 공고 전부. 제외 사유별로 골라 볼 수 있어 잘못 빠진 공고를 찾을 때 씁니다. |
| **직접 검색** | 불러온 공고 전체에서 공고명·수요기관·공고번호로 찾습니다. |
| **과거사업 목록** | 싱크로율 비교에 쓰는 지일 과거 실적. 연도별로 정리돼 있고 누르면 과업 내용이 보입니다. |

- 실제 공고 탭에서는 **"확인 필요" 필터**(실적·현장설명회 등)와 **검색창**을 쓸 수 있습니다.

## 3. 카드 보는 법

### 맨 위 줄
- **마감 D-N**: 마감까지 남은 날수
- **협상 / 입찰 / 규격가격동시입찰 / 사전규격**: 공고 종류
- **용역 / 물품 / 공사**: 업무 구분
- **오른쪽 숫자(%)**: 싱크로율. 누르면 비슷한 과거 실적 목록이 나옵니다.

### 마감 날짜
- 점선 밑줄이 있는 **날짜에 마우스를 올리면** 일정 전체가 나옵니다(공고 게시·자격등록·공동수급협정·입찰·개찰).
- ★ 표시가 카드의 D-N 기준입니다.

### 참가 조건 칸

| 칩 색 | 뜻 |
|---|---|
| 🟩 초록 | 충족 (예: 자격요건 충족, 지역 충족) |
| 🟥 붉은색 | 미달 (예: 자격요건 미달, 지역 미달) |
| 🟧 주황 | 사람이 직접 확인해야 할 요건 (실적 요건, 현장설명회, 기술인력 요건, 건축사사무소 요건) |
| ⬜ 점선 | 제한 없음 또는 정보 없음 |

- **모든 칩에 마우스를 올리면** 설명이 나옵니다.
  - **자격 칩**: 필요한 면허 목록이 나오고, 보유하면 ✓, 없으면 ✗로 표시됩니다.
  - **지역 칩**: 참가 가능 지역과 지일 소재지가 나옵니다.
  - **주황 칩**: 핵심 내용(실적은 기간·금액, 현장설명회는 일시·장소 등)과 공고문 원문, 출처 파일 이름이 나옵니다.

### 싱크로율 등급

| 표시 | 기준 | 뜻 |
|---|---|---|
| 높음 | 65% 이상 | 지일이 비슷한 일을 해 본 적 있음 |
| 경계선 | 45~65% | 일부 과업만 비슷함 |
| 낮음 | 45% 미만 | 지일이 해 본 일과 거리가 있음 |

- "공고명만"이라고 표시된 점수는 첨부파일 없이 공고명으로만 계산한 것이라 덜 정확합니다.

## 4. 알아두실 점

- **자격 미달·지역 미달이어도 목록에서 빠지지 않습니다.** 공동수급으로 참가할 수 있는 경우가 있어서 표시만 하고, 판단은 담당자께 맡깁니다.
- **주황 칩(확인 필요)은 자동으로 판정하지 않습니다.** 지일이 조건을 갖췄는지는 원문을 보고 직접 확인해 주세요.
- 공고문 형식에 따라 **요건이나 마감을 못 찾는 경우가 있습니다.** 이상하면 칩의 원문과 출처 파일을 확인하고, 사례를 알려주시면 고칩니다.
- 화면이 이상하거나 예전 모양으로 보이면 **F5(새로고침)**를 눌러 주세요. 그래도 같으면 "나라장터에서 불러오기"를 다시 해 주세요.
- 참가여부(참가·불참)를 꼭 남겨 주세요. 이 기록으로 키워드를 고칩니다.

## 5. 앞으로 남은 과제

| 과제 | 상태 |
|---|---|
| **실적 요건 자동 판정** | 지일 실적 목록(사업명·금액·준공일)을 받으면 "실적 충족/미달"까지 자동으로 보여줄 예정 |
| **키워드 정리** | 참가/불참 기록이 몇 주 쌓이면 제외 키워드별로 집계해 손봄. "기념관"·"홍보관" 추가, "전시부스"를 "부스"로 넓힐지 결정 대기 |
| **싱크로율 기준 보정** | 65%/45% 기준을 실제 참가 결과와 비교해 조정 |
| **텔레그램 보고서** | 10/12부터 자동 발송: **입찰 공고는 매일 아침 8시**(어제 올라온 공고), **협상·규격가격동시입찰·사전규격은 매주 월요일 아침**(지난 7일). 메시지 모양은 다듬는 중 |
| **판정 정확도 점검** | 실제 공고와 대조하며 잘못 잡힌 칩·빠진 요건을 계속 고침 |
