# 2026-10-22 작업 내용

시각은 한국 시간이다.

## 1. 제외 탭 '세부품명 미달' 칩 — 사전규격 구분, 팝업 정리 (브랜치 `claude/prespec-product-chip`)

| 문제 (사용자 제보) | 고친 것 |
|---|---|
| 사전규격도 "세부품명번호 미달" — 본공고 파싱 오류인지 사전규격이라 정보가 없는 건지 구분 안 됨 | 사전규격이고 세부품명이 비었으면 칩 **"사전규격 · 품목 정보 없음"**(회색 점선, 사용자가 고른 이름). 제외 사유 칸 품명코드 줄도 "사전규격이라 세부품명번호 정보 없음" |
| 팝업이 긴 한 줄 문장이라 읽기 어려움 | 자격 팝업(세부품명번호 2건)과 같은 모양 — "관심 키워드" / "용역분류(나라장터)" 또는 "세부품명번호" 칸마다 ✗·– 한 줄, 이유는 그 아래 작은 글씨 |

- 사전규격이어도 세부품명 이름이 있으면(물품 등) 실제로 안 맞은 것이라 "세부품명번호 미달" 그대로, 팝업 제목에 "(사전규격)".
- 서버(`webapp/mview.py`)가 키워드·품목 단계에 `what`·`name`을 더 실어 보냄 — 서버 재시작 + 다시 불러오기 뒤에 새 팝업. 예전 결과는 예전 문장 그대로.
