## 5. 예외 낱말 판단 파일 자동 반영 (PR #232, 병합)

- 사용자 결정: 파일을 주고받지 않게, **병합까지 자동**.
- 서버 PC에서 HTML을 열고 '제출'하면 다운로드 폴더(`EXCLUSION_INBOX`, 없으면 ~/Downloads)에 생긴 파일을 웹앱이 1분 안에 찾아
  (`webapp/exclusionsync.py`) `python -m nego.exclusion_apply 파일`을 돌림:
  ① jiil 판단 기록·`evaluation/exclude_words.json`에 넣음 ② 과거 프로필 다시 만들고 jiil 테스트 통과 시 PR 만들어 병합
  ③ 싱크로율 묶음 다시 잠가 이 레포 PR 병합 ④ 개발자 방에 결과 알림. 어느 단계든 실패하면 병합 안 하고 실패만 알림.
- 두 레포 모두 임시 작업 폴더(git worktree)에서 해서 열려 있는 작업 폴더는 안 건드림. 처리한 파일은 내용 해시로
  `data/exclusion_applied.json`에 남김 — 체크를 고쳐 다시 제출하면 새로 반영, 이미 반영한 판단은 건너뜀.
- 규칙(정규식)은 자동으로 안 바꿈 — 영문 낱말이 승인되면 낱말로 넣고 "규칙으로 처리하는 게 나을 수 있음"으로 알림.
- 필요한 것(서버 PC): `.env`의 `CORPUS_PASSPHRASE`·`TELEGRAM_BOT_TOKEN`·`TELEGRAM_DEV_CHAT_ID`, gh 로그인, 옆에 클론한 jiil 레포.
  휴대폰에서 제출한 파일은 서버 PC로 안 오므로 '결과 복사' 글을 Claude에게 줌.
- 시험: `python -m nego.exclusion_apply 파일 --dry-run`(올리거나 병합하지 않음), 이미 손으로 반영한 파일은 `--mark-done`.
