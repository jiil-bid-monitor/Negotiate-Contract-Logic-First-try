# 2026-11-03 작업 기록 — NAS 메모리 실측

NAS: Synology DS923+, Ryzen R1600 2코어·4GB. 아래 값은 모두 NAS가 아니라 Windows PC에서 잰 값 — NAS(리눅스)에서 다시 재야 확정.

## 1. OCR 메모리 (이 PC, 스캔 서류 4쪽)

- PP-OCRv5 mobile, 150dpi, `cert_ocr` 방식 그대로. 최고 **1,236MB**.
- 평소 쓰는 양이 쪽마다 약 50MB씩 늘어남(1쪽 565MB → 4쪽 686MB) — 한 번에 읽는 쪽수를 정하고 끝나면 프로그램을 내릴 것.
- 1쪽 20~43초. NAS에서는 1쪽 1~2분으로 짐작.

## 2. 웹앱 "나라장터에서 불러오기" 메모리 (서버 PC, 담당자 측정)

조건: 최근 30일 + 사전규격 + 첨부 읽기. 7일은 아직 안 잼.

| 항목 | 값 |
|---|---|
| 시작 직후 | 625MB (최고 768MB) |
| 수집 중 최고 | **2,514MB** |
| 끝난 뒤 | 1,577MB (실제 점유 2,638MB) |
| 시간 | 수집 65분 + 세부품명 확인 8분 |

단계별: 공고 목록 받기 640 → 1,096MB / 첨부 읽기 1,200~1,950MB, 순간 최고 2,452MB / 결과 정리·저장(싱크로율 포함) 1,969MB, 순간 최고 2,514MB.

## 3. 판단

- 4GB에 대 보면 DSM 약 1GB(짐작) + 웹앱 수집 2.5GB + OCR 1.24GB = 약 4.7GB. **30일 수집은 웹앱 상한 2GB(`docker-compose.yml`)를 넘음.**
- 수집이 끝나도 메모리가 시작 때로 돌아오지 않음(625MB → 1,577MB).

## 남은 것 / 결정 대기

- **사용자 기준: 30일치를 다뤄야 함** — 공고를 놓치지 않고, 놓쳤다면 제외 공고까지 보며 원인을 찾기 위해. 9/30의 "첫 주만 30일, 이후 7일" 운영을 대체.
  'NAS에서는 7일까지만'은 후보에서 빠지고 7일 실측도 필요 없음.
- **사용자 제안: 수집은 지금처럼 서버 PC 웹앱에서 담당자가 누름**(Actions로 옮기지 않음).
- 웹앱 화면을 어디에 둘지 — 결정 전:
  - 서버 PC에 그대로: 바꿀 것 없음, PC가 꺼지면 화면도 멈춤.
  - 화면만 NAS: PC가 꺼져도 화면이 돌아감. 수집 결과를 NAS로 넘기는 기능과 불러오기 버튼·판단 기록 저장 위치 정리가 필요하고, 30일 결과를 띄울 때 NAS 메모리를 재야 함. 아직 안 만듦.
- 그 밖의 후보: NAS 메모리 증설, 웹앱 메모리 줄이기.
