## 1. 참가자격·통합본

- 이름만 적힌 증빙(중소기업확인서·직접생산확인증명서 등)은 '필수 서류' 줄. '이 중 하나' 자격은 통합본에 하나만.
- 제출 파일은 둘: 회사 서류 원본을 이은 `통합본.pdf` + 직접 기입할 `통합서식.hwpx`(한글 하나로 합치는 안은 PDF 원본이 그대로 안 붙어 되돌림).
- 직접생산확인증명서 14개가 다 들어가던 것(PDF 줄바꿈 때문) 고침.

## 2. 서식 채우기 정확도

- 글자 겹침(줄 간격 50% 칸) → 한 줄에 맞춤, 숫자·영문 글꼴을 한글과 같게.
- 수행실적은 준공된 것만.
- 연혁·등록증·사업자등록증 PDF에서 빈 회사정보(전화·팩스·대표자 주민번호 앞자리·업태·종목) 채움, 서류 종류는 파일 이름 + 글 내용으로.
- 주민번호는 앞 6자리만, '해당 없음' 기재, 'TEL : FAX :' 칸 안 빈자리, '(인)' 칸, 서명 줄('대표자 : (인)', '(인 또는 서명)').
- 필암서원 결과물(서버에서 만든 hwpx·pdf) 정밀 비교 → 빈 칸 고침: 글 안 태그가 낀 이름표, 대표이사·대표사 업체명·생년월일(사업자등록번호),
  표지 칸, 쌍점 없는 '주소/상호/대표자' 줄, 입찰명·입찰건명·공고명, 업태·종목.
- 정렬: 같은 열 번호 칸은 가운데 정렬 칸에 맞춤, '(인)' 칸에 넣은 이름은 가운데.
- 서식 28(장비 공급확약서) 발행자(제조사) 칸에 지일 정보가 들어가던 오류 → 비움, '공급받는 자'에 회사명.
- 서식 19 '○○○업체 대표자 : ○○○' 자리표시 채움(서식 23 봉투 예시는 그대로 — 사용자 결정).
- 공고번호 칸 = 나라장터 입찰공고번호+차수(R26BK01806620-000). 처음에 장성군 공고번호(제2026-1129호)를 넣었다가 사용자 정정.
- 서식 2 하단 '신청인 : 대표자 (주)지일  대표자 성명 : 이운봉 (인)'.

- 전화·팩스가 계속 비던 원인: 등록증 PDF가 묶음 밖에 있었음 → 묶음 밖 PDF(jiil-quant-docs 폴더 맨 위)도 읽음, `py -m quantdocs vault check` 점검 명령.
  서버 결과: 전화·팩스·주민번호 앞자리·업태·종목 모두 읽힘.

  `.env` 값은 작은따옴표로(start.sh가 bash로 읽어 빈칸에서 끊김). 인감증명서 OCR 확인.
