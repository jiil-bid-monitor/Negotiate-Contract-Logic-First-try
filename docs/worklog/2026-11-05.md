# 2026-11-05 작업 기록 — 정량평가서(브랜치 `claude/quantdocs-merge`, main 미병합)

## 1. 채운 글 11pt 통일 (완료, 서버 PC 확인 대기)

- 계기: 서식 '주 소' 칸 캡처 + "폰트 크기 11pt로 통일해줘".
- 사용자 선택: 자동으로 채운 글은 모든 서식에서 11pt(서식 원래 글자는 그대로), 칸에 한 줄로 안 들어가면 줄이지 않고 두 줄로.
  줄 간격이 좁은(100% 미만·고정값) 칸만 두 줄이면 글이 겹쳐 예외로 줄임.
- 칸 전체를 채운 글 + 이름표 뒤에 끼워 넣은 값(TEL·FAX·업체명·서명 줄)까지 11pt. 같은 줄의 이름표는 원래 크기.
- 확인: 정선 실제 제안요청서 21개 서식을 가짜 회사 정보로 채워 통합서식까지 — 채운 값 전부 11pt, 파일 구조 정상, 서식 1 그림 확인. 테스트 729개 통과.
- 남은 것: 서버 PC에서 필암서원 다시 만들어 한글로 확인(11/04 남은 확인과 함께).

## 2. 투찰 계산기 순공사원가 안내 (질문 답변, 코드 그대로)

- '순공사원가 금액은 있는데 조건 문장을 못 찾아 반영하지 않음' 안내 질문 — 계산은 금액만으로 가능, 10/29 결정(98% 고정 안 함)으로 문장을 찾을 때만 반영.
  제안: 금액이 있으면 문장을 못 찾아도 98%로 반영(못 반영하면 무효 위험, 반영하면 금액이 조금 높아질 뿐) — **사용자 결정 대기**.
- 사용자 공고(기초금액 193,283,304·순공사원가 158,182,511·하한율 89.745): 문장을 반영해도 추천 금액 그대로(순공사원가 98% 선 155,871,465원 < 하한선 174,416,144원).
  공고문에 실제 문장이 있는데 못 읽은 원인은 공고번호를 받아 확인할 것.

## 3. 이름표 문단 값이 둘째 줄로 넘어갈 때 들여쓰기 (완료, 서버 PC 확인 대기)

- 계기: '주 소 : 강원특별자치도 정선군 남면' 다음 줄 '무릉2로 64(공장1층)'이 줄 맨 앞에서 시작 → 값 시작 위치에 맞춰 이어지게(내어쓰기).
- 너비는 탭·빈칸·글자 크기로 어림 — 몇 mm 어긋날 수 있어 서버 PC에서 한글로 확인 필요. 정선 실제 서식 서명 줄 55곳에 적용, 파일 구조 정상, 테스트 730개 통과.

## 4. 제목과 표가 다른 쪽으로 갈라지는 서식 (완료, 서버 PC 확인 대기)

- 제보: 서식 12 '제안회사 일반현황 및 연혁' — 첫 쪽에 제목만, 표는 다음 쪽. 다른 서식에도 더러 있음.
- 원인(서버에서 만든 zip으로 확인): 원본부터 표가 쪽 끝까지 0.2mm만 남는 서식(필암서원 서식 2 부근·12·16)인데, 채운 업태·종목이 두 줄이 되며 표가 길어져
  통째로 다음 쪽으로 넘어감('글자처럼 취급' 표는 쪽에서 안 나뉨). 둘째 쪽 표 아래 여백은 제목이 없어서 생긴 자리.
- 고친 것: 채운 글로 표가 쪽 남는 공간보다 길어지면, 같은 표에서 여유가 많은 줄(주요연혁 빈 칸 등)을 그만큼 줄여 표 전체 높이를 원래대로. 글자 크기(11pt)는 그대로.
  필암서원 실제 서식: 서식 2 4.0mm·서식 12 6.0mm 줄임, 나머지는 쪽 여유가 있어 그대로. 줄일 여유가 없는 표는 알림만.
- 테스트 731개 통과. 서버 PC에서 한글로 서식 2·12·16이 제목과 한 쪽에 있는지 확인 필요.

## 5. 통합서식 빈 쪽 (완료, 서버 PC 확인 대기)

- 제보: 통합서식 중간에 아무것도 없는 쪽. 원인: 서식 끝에 남은 빈 문단이 다음 쪽으로 넘어가 혼자 한 쪽을 차지(서식 5 '장성군수 귀하' 뒤), 다음 서식은 다시 새 쪽.
- 고친 것: 서식을 이을 때 서식 끝·'새 쪽' 앞 빈 문단을 지움. 필암서원 제안요청서 빈 문단 10개 빠짐. 테스트 732개 통과.

## 6. 산출내역서·사업수행능력 배점기준 (질문 답변)

- 서식 22 산출내역서: 세부 과업(공정)별 사업비 → 총사업비(= 제안금액, 상한 4억), 가격제안서와 함께 밀봉. 담당자가 직접 기입(프로그램은 안 채움).
- 배점기준 위치: 제안요청서 「3. 제안서 평가기준 → 〈별표1〉 주1) 정량적평가 20점」. 확인 필요 두 가지(서면질의 11/3~11/9, FAX·이메일, 1회):
  서식 24 '누계 4 + 단일최대 2' vs 본문 '누계 6', 본문 배점표(5.5억 이상 만점) vs 주석(사업비 4억 이상 만점).

## 7. 정량평가 자기평점 자동 계산 (완료 — 회사 자료 대기)

- 사용자 요청: "제안요청서를 기준으로 항상 계산되게". 결정: 관련 서류(인력·특허·신용등급)는 나중에 받으니 로직만, 본문 표와 주석이 다르면 배점표 + 알림.
- 공고마다 제안요청서 본문 정량평가 표를 읽어 서식 24 자기평점 칸과 준비표 '자기평가' 시트에 점수·근거·확인할 것. 자료 없는 항목은 비움.
- 회사자료 양식에 '특허목록' 시트, 회사정보에 신용평가등급·신용평가 종류·신용평가 평가일·부정당업자 제재처분 추가 — 서류 받으면 양식에 적고 다시 잠금.
- 테스트 734개 통과. 필암서원 제안요청서로 배점기준 다섯 항목 읽힘, 가짜 자료로 서식 24 채움 확인.
