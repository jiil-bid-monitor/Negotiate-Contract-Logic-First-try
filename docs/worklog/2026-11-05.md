## 1. 채운 글 11pt 통일 (완료, 서버 PC 확인 대기)

- 계기: 서식 '주 소' 칸 캡처 + "폰트 크기 11pt로 통일해줘".
- 사용자 선택: 자동으로 채운 글은 모든 서식에서 11pt(서식 원래 글자는 그대로), 칸에 한 줄로 안 들어가면 줄이지 않고 두 줄로.
  줄 간격이 좁은(100% 미만·고정값) 칸만 두 줄이면 글이 겹쳐 예외로 줄임.
- 칸 전체를 채운 글 + 이름표 뒤에 끼워 넣은 값(TEL·FAX·업체명·서명 줄)까지 11pt. 같은 줄의 이름표는 원래 크기.
- 확인: 정선 실제 제안요청서 21개 서식을 가짜 회사 정보로 채워 통합서식까지 — 채운 값 전부 11pt, 파일 구조 정상, 서식 1 그림 확인. 테스트 729개 통과.
- 남은 것: 서버 PC에서 필암서원 다시 만들어 한글로 확인(11/04 남은 확인과 함께).

## 2. 투찰 계산기 순공사원가 안내 (질문 답변, 코드 그대로)

- '순공사원가 금액은 있는데 조건 문장을 못 찾아 반영하지 않음' 안내 질문 — 계산은 금액만으로 가능, 10/29 결정(98% 고정 안 함)으로 문장을 찾을 때만 반영.
  제안: 금액이 있으면 문장을 못 찾아도 98%로 반영(못 반영하면 무효 위험, 반영하면 금액이 조금 높아질 뿐) — **사용자 결정 대기**.
- 사용자 공고(기초금액 193,283,304·순공사원가 158,182,511·하한율 89.745): 문장을 반영해도 추천 금액 그대로(순공사원가 98% 선 155,871,465원 < 하한선 174,416,144원).
  공고문에 실제 문장이 있는데 못 읽은 원인은 공고번호를 받아 확인할 것.

## 11. 정량평가서 수정 요청 14가지 (완료 — 서버 PC·한글 확인 대기)

사용자가 준 목록 그대로 반영. 필암서원·국민안전체험관 실제 서식에 가짜 회사 자료로 만들어 확인(XML 정상, 서식 5·24·6 그림 확인). 테스트 740개 통과.

1. 첨부는 **공고문·제안요청서만** 읽음(파일 이름에 '공고'·'제안요청') — 과업지시서·도면 등은 안 읽고 화면 알림에 이름. 둘 다 없으면 전부.
2. 청렴계약 이행서약서 '서 약 자 : (인)' = 대표자 이름.
3. 입찰보증금 지급 확약서: 입찰 금액 = 제안요청서 기초금액(없으면 사업비·사업예산, 그다음 공고문) '금 400,000,000원(금 사억원)',
   보증금 = 그 금액 × **1.05**(사용자 확인 — 4억이면 '금 420,000,000원(금 사억이천만원)').
   보증금 글이 없는 서식(가격제안서)의 입찰금액 칸엔 안 넣음.
4. 위임장 '대리인' 묶음의 주소 칸은 비움(회사 주소 줄은 그대로).
5. FAX: 서버 PC `.env`의 `QUANT_FAX`(전화는 `QUANT_TEL`)가 회사 자료 값보다 먼저 — 번호는 공개 저장소에 안 적음.
6. 실적 금액은 머리글 단위(천원·백만원)와 상관없이 원 단위 전체(절사 없음), 합계도 — 단위는 담당자가 고침.
7. 실적은 **기간 조건만** — 서식 제목·작성 안내의 '최근 N년' 안에 준공된 실적 전부(분야·단일 금액 하한으로 안 거름).
   '체험물 제작·설치 실적'처럼 제목에 '실적'만 있는 서식도 채움('납품(도급)액'·'준공년월일' 칸, '실적 누계 | 건 | 천원' 줄). 실적증명서는 그대로.
8. 자기평가 심사표 '생년월일(사업자등록번호)' = '법인등록번호 (사업자등록번호)'(위임장 '법인등록번호(사업자등록번호)' 칸도 같은 모양).
9. 자기평점: 제안요청서 배점표·계산 조건대로 계산하되 **서식 배점 기준과 다르면 서식 기준**, **계산식끼리 다르면 유리한 쪽**.
   - 서식 표 안에 구간·등급이 적힌 자기평가표(국민안전체험관 서식 6 — '평 점' 칸)는 서식 구간으로 계산.
   - 줄마다 배점만 적힌 서식(필암서원 서식 24)은 본문 점수를 서식 배점에 맞춰 환산(본문 누계 6점 → 서식 4점이면 × 4/6),
     본문에 없는 '단일최대' 줄은 본문 구간을 가장 큰 실적 한 건에 적용해 환산(확인 알림).
   - 유리한 쪽 예: 필암 주석 '사업비 4억 이상이면 만점' vs 배점표 5.5억 → 주석대로 만점(예전 결정 '배점표 + 알림'을 바꿈),
     국민 인력 본문 '4.2 + ∑' vs 서식 '미보유 시 4.2' → 4.2 + ∑.
   - 본문 정량평가 절 읽기 고침: '2) 정량적 평가 지표: 20점' 아래 '가) 사업수행실적: 6점' 머리, '3) 입찰가격 평가'에서 멈춤, '(10억 이상 실적)'은 구간이 아니라 단일 하한.
10. 신인도 = 늘 배점 만점(2점) — 회사정보에 제재처분이 적혀 있으면 알림만.
11. 경영상태 = 회사정보 '신용평가등급'·'신용평가 종류'(서류 받으면 적음) — 로직은 그대로.
12. 기술인력 = 인력목록(이름·등급) — 서류 받으면 적음. 특허목록 시트가 비면 '자료 없음'(예전엔 0건으로 셈).
13·14. 서면질의서·질의서·공동수급 서류(협정서·대표자 선임계·합의각서)는 채우지 않고 양식 그대로(공란).

이어서 사용자 결정: 보증금은 × 1.05로 고침, **자기평점 자동 채점은 기술인력·경영상태(신용평가)·신인도만** — 실적·특허는 비우고 담당자가 직접(계도 비움).
FAX는 서버 PC `.env`에 `QUANT_FAX` 한 줄(이 세션에서 서버 PC에 연결할 수 없어 사용자가 명령으로 넣음). 남은 확인: 한글로 서식 5·24 확인.

## 12. 회사 연혁(한글 파일) 읽기 (완료 — 서버 PC에 파일 넣기 대기)

- 고친 것: jiil-quant-docs 폴더 맨 위(또는 묶음)의 한글 파일도 읽음 — 앞부분에 '연혁'·'일반현황'이 있는 문서만. 표처럼 날짜만 한 줄·내용 다음 줄인 모양,
  내용이 두 줄로 넘어간 칸도 읽음. 앞쪽 일반현황 표의 회사명·대표자·주소·전화·팩스·사업자번호·자본금은 회사정보가 빈 칸일 때만 씀.
- 받은 파일로 21줄 읽힘, 필암서원 서식 12 '주요연혁' 칸에 들어간 것 그림으로 확인. 테스트 741개 통과.
