# 2026-11-12 작업 정리 — 회사 서류 만료 알림 (텔레그램 봇)

자세한 결정·규칙은 `CLAUDE.md`, 텔레그램 기능 설명은 `docs/telegram.md`. 회사 자료는 저장소에 올리지 않음.
이 파일은 회사 서류 알림 작업만 적음 — 같은 날 다른 세션에서 한 일(정량평가서·수의계약 수집·낙찰 후 서류 등)은 `CLAUDE.md`의 11/12 절 참고.

## 1. `/upload`로 올린 서류 반영 확인

- 텔레그램 `/upload`로 올린 직접생산확인증명서(전시홍보관설치및디자인서비스)가 NAS에 반영된 것을 확인.
  - `회사서류_최신\[최신 서류]`에 `…_2026-11-12_유효2028-11-11.pdf`로 저장, 예전 파일은 `[이전 서류]`로 옮겨짐.
  - `_목록.json`·`서류목록.xlsx`도 새 날짜로 바뀜.
  - `인증서갱신.xlsx`엔 이 서류 줄이 없어 그대로 — 알림은 `서류목록.xlsx` 날짜를 씀.

## 2. 만료 알림을 한 달 전·7일 전 두 번 (PR #355, main 병합·NAS 반영)

- 사용자 요청: 유효기간 **한 달 전, 일주일 전** 두 번 알림. 예전엔 7일 전 한 번 + 당일.
- 지금 알림 시점: **30일 전 → 7일 전 → 당일**. 서류마다 단계별로 한 번씩만(`data/doc_alerts_sent.json`).
- `webapp/docexpiry.py` `ALERT_MONTH = 30`, 알림 머리글 "30일 안에 유효기간이 끝납니다".

## 3. 서류 상태 표시 — '신청해야 함'·'신청 중' (PR #356, main 병합·NAS 반영)

- 계기: 그리다 서류는 갱신 신청은 했고 서류만 아직 안 나옴 — 표시해 두면 "발급 받으면 `/upload`로 올려 달라"는 알림이 가게.
- 처음엔 '신청 중' 하나만 만들었다가, 사용자 요청으로 **'신청해야 함'(아직 신청 전)·'신청 중'(신청함, 서류 대기)** 두 가지로 바꿈.
- 쓰는 법: 만료 알림과 `/docs` 답장 아래 서류마다 **"상태 표시: 서류 이름"** 버튼 → 누르면 "신청해야 함 / 신청 중 / 표시 지우기"를 물음.
  - 버튼은 30일 안에 끝나는 서류, 그리고 만료가 지났어도 상태를 표시해 둔 서류에 나옴.
- 표시하면
  - `/docs` 목록에 "· 신청해야 함" 또는 "· 신청 중"이 붙음.
  - 다음 알림에 "신청해야 함 — 갱신 신청을 해 주세요" 또는 "신청 중 — 발급 받으면 /upload 로 최신 서류를 올려 주세요" 줄이 붙음.
  - **만료일이 지나도 새 서류가 올 때까지 7일마다 다시 알림**(표시 안 한 지난 서류는 예전처럼 안 알림).
- `/upload`로 새 날짜가 들어오면 표시는 저절로 풀림(기록 키가 '종류|만료일'이라).
- 기록은 NAS `data/doc_applying.json`(`{"종류|날짜": "n"|"p"}`). 코드 `webapp/docexpiry.py`(`STATES`·`apply_buttons`·`apply_callback`·`due_alert`), `webapp/telegrambot.py`(`handle_apply`), 시험 `tests/test_docexpiry.py`.
