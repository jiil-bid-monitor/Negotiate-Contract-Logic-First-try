## 1. 정량평가서 (quantdocs) — 서식 채우기 규칙
- 이름표: 입찰참가 신청자 = 회사명, 계약상대자등록번호 = 사업자등록번호, 법인등기부등본(생년월일·주민번호) = 법인등록번호, 기관(회사)명·대표자 성명, '입찰공고' = 나라장터 번호.
  글자 수 대신 낱말(끝쪽 낱말)로 이름표 판별, 안내 문장은 제외.
- 표 머리글 먼저 보기: 점검표(적용·해당없음 등) 열·건수/금액/기간 열엔 회사 정보 안 넣음, 증명서 발급기관·위탁자·하수급인 쪽은 비움.
- 서명 줄: 서식 모양(문단)은 안 바꾸고 값만, 길면 낱말 사이 줄바꿈(값 시작 위치에 맞춤), 가운데 정렬 묶음은 이름표 자리 유지,
  값은 늘 ':' 옆, 미리 적힌 ':'는 남김, 자리표시(○○○·o o o·000), '신청인(대표사) (인)', 괄호 없는 '인', 보안 서약서 서약자(소속·직위·성명).
- 공동수급 구성원용으로 되풀이되는 회사 표는 첫 표만.
- 자기평가표: 가로 신용등급 표, 계량부문 '배점의 N%', 감점 칸 늘 0, 감점 항목 만점·합계 표, 기술인력 등급 줄·비고 '명 × 점 = 점'.
- 실적 표 '①계약명', 입찰보증금 '원정'·'용역비', 보증금율 '5%'(PR #397 병합 대기 — 원본에 없던 금액은 안 붙임).
- 서식 인식: '【양식N】', 【별표 N】(공란 서식 뒤), 쪽 테두리 표 안 표.
- 통합서식을 못 만들면 늘 경고(이유와 함께).
- 칸 안 'fax'·'팩스번호:', 표 밖 전화·이메일 줄 벌어짐(남는 탭 빼기).
- 원칙(사용자): 채운 서식에서 원래 있던 글·이미 넣던 값은 임의로 빼지 않음, 원본에 없던 값도 함부로 붙이지 않음.

## 2. 투찰내역
- 비교 기록(기록 금액 ≠ 실제 투찰 금액) — 웹앱 금액 기준 순위·사정률, 실제 투찰 순위 같이.
