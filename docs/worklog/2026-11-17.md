- 원문에 규칙이 없는 칸은 점수를 지어내지 않고 '확인 필요'(이유·볼 곳·근거) — 기술용역 경영상태 빈칸 등.
- 기술용역에서 원문과 달랐던 것 고침: 학술 신인도 한도 +3, 부정당업자 감점, P.Q 지역 '미적용' 3점은 P.Q 환산에 합산.
- **제출서류 목록표를 원문 글자 그대로** — 물품·공사·기술용역·강원·경기·경남·조달청 7가지. 예전엔 줄을 줄이거나(공사 19 → 6줄) 원문에 없는 괄호 설명('(단순노무만)')·'주)'를 붙였음 → 허위로 보고 뺌.
- 목록표의 **서류마다 탭**(탭 번호 = 원문 연번): 회사서류_최신에 있으면 그림으로 자동, 없으면 지일 자료 폴더에서 이름으로 한 번 더 찾아 '확인N_' 탭(인쇄 안 됨), 그래도 없으면 빈 탭 + 노란 설명 상자.
- 기술용역 틀에 원문 별지 서식(제4~10호) 탭 — 회사 칸·제출처·증명서 용도 자동, 실적은 '실적선택' 탭에서 O 표시(준공된 것만 들어감).
- 읽어보기에 금액 구간별 차이 표(일반용역·기술용역).
- 여성기업은 '아니오' 그대로(11/16 사용자: 이제 해당 없음 — 2024년 확인서는 공동대표 때 것, 최신 등기는 이운봉 단독대표).

## 2. 대금 청구서 표준틀 (실습폴더 `청구서_표준틀`)
- 샘플(평창군 관문경관 조형물 청구본)의 탭·서식·문구 그대로, 바뀌는 값만 '기본사항'에서. 열면 '기본사항' 탭부터.
- 칸 색 = 적격심사 틀과 같음: 파랑 계약서 값·자동 계산 / 초록 회사 정보 / 노랑 담당자(선급금·완료일·청구일).
- 청구액 = 계약금액 − 선급금(다르면 덮어 적음), 맨 아래 왼쪽 '○○ 귀하' 늘 보임, 수신자·귀하는 안내 칸에 ✎ + 누르면 설명 상자('발주처가 다른 사람으로 해 달라면 고침').
- 통장사본: 우리은행 통장표지 PDF(11/17 출력)를 은행 내용만 300dpi로 — 예전 그림(464×505)은 아무리 키워도 깨졌음.
- 주소: 강원도 → 강원특별자치도('(공장1층)'은 칸에서 잘려 뺌).
- 엑셀 '복구' 창 원인: 샘플에 딸려 온 이름 정의 2,421개(외부 참조·#REF!) — 모두 지움. 원본 `003_청구서-지일.xlsx`는 그대로라 여전히 복구 창이 뜸.
- 웹앱 낙찰 후 서류에는 아직 연결 안 함(준공계·완수계와 함께).

## 3. 낙찰 후 서류 — 묶음 zip + 사내 공유 폴더 (#453)
- 폴더 만들기를 누르면 공고 폴더 전체 `번호_전체.zip`을 바로 내려받음.
- NAS 웹앱 컨테이너는 `jiil-webapp`만 볼 수 있어 **서버 PC가 1분마다** NAS `낙찰후서류` ↔ 사내 공유 폴더(지금 시험 = 실습폴더 `낙찰후서류_시험`)를 맞춤(`webapp/awardsync.py`).
  기준 = 사내 공유 폴더(담당자가 거기서 고침), 늦게 고친 쪽이 이김, 지우지 않음 → 폴더 정리는 양쪽에서.
- 서버 PC `.env`에 `POSTAWARD_SHARE_DIR='\\jiilserver\002 진행프로젝트\실습폴더\트랙1_파일 자동 생성\낙찰후서류_시험'`(작은따옴표 필수 — 경로 띄어쓰기) 넣고 다시 켬.
- 실측: NAS → 사내 공유 5초, 사내 공유에서 고친 내용 → NAS 65초. 시험 파일은 양쪽 지움.
- NAS 코드는 이 PC에서 NAS 저장소 `git pull` + `control\restart-webapp`으로 반영(이미지 다시 빌드 전이라 NAS가 스스로 못 받음).
- **NAS 리빌드 때 함께 할 일**을 CLAUDE.md에 모음: 사내 공유 폴더 직접 연결(그때 서버 PC 동기화 끔), git 자동 받기, 1억 미만 결과 위치, requirements.
