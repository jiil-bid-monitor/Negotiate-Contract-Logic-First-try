## 1. 투찰내역 결과 표시 (서버 코드 일부 — 웹앱 다시 켜기)
- 개찰 결과 칸 = '낙찰'·'탈락'만 + 안 낸 쪽 등수 한 줄(웹앱 N등 / 외주 M등), 오른쪽 '지일 등수' = 실제 투찰 등수만. 같은 등수 두 번 안 씀.
  지일 순위가 없으면 나라장터 비고를 짧게('예가초과'), 없으면 '순위 없음'. 위 '외주 vs 웹앱' 요약 줄은 뺌.
- 외주 금액 칸이 빈 기록에 지일 실제 투찰 금액이 웹앱 금액과 다르면 그 금액을 외주 금액으로 한 번 넣음(`fill_outsource`, `outsourceAuto` — 지우면 다시 안 넣음).
  계기: 지방도411호선 강림지구 낙석방지책(R26BK01815406).
- 펼친 결과·머리 요약·투찰 업체 표 번호 = 지일이 실제로 낸 금액 기준(장수 한글놀이터 R26BK01804442 — 웹앱 1등, 실제 2등). 비교 상자는 '웹앱 기록 금액으로 투찰했다면'.
  성적표·보정 방향·'분석용 웹앱' 칩은 그대로.

## 2. 투찰 계산기 (서버 코드 — 웹앱 다시 켜기)

## 3. 통합서식이 한글에서 안 열림·멈춤 (장성 월남 참전 기념탑 R26BK01839485)
- '손상·변조 가능성' — 쪽 설정만 남긴 문단의 낡은 줄 배치 지움(사용자 PC에서 이 문단 하나만 고친 파일이 열림 확인).
- 둘째 서식 뒤 멈춤 — 이을 때 서식마다 들어간 쪽 설정을 구역 첫 문단 하나만 남김.
- 1쪽 여백 — 쪽 설정 빈 문단 없앰(첫 문단 안으로), 첫 쪽 4분의 1만 쓴 서식도 쪽 맞춤, 전체 가늠이 안 되면 서식마다 가늠.
- 남은 것: 고친 코드로 새로 만든 통합서식을 한글에서 열어 보기(사용자 확인 대기).

## 4. 정량평가서 채우기 규칙
- 공란: 이름에 '공동수급'이 없어도 본문이 공동수급 대표자 위임·선임이면 공란 / '공동제안자'·'공동수급인'·'공동도급인' 서명 묶음 비움(대표 묶음만 지일).
- 대표님 개인 번호는 어느 서식에도 안 넣음 — 휴대폰 칸 모두 회사 전화(11/16·11/18 '대표자 휴대폰'을 대체).
- 서명 줄: '(인)(사용인감)', '대 표 :', 이름표 뒤 자리표시('회사명 ○ ○ ○ / 대 표 ○ ○ ○ (인)'), ':' 자리는 지키고 값 뒤 빈칸만 줄여 '(인)'이 같은 줄에(가운데 정렬 묶음 포함).
- 칸: '(전화 : )'·'FAX번호 :', 단위가 미리 적힌 칸('명'·'백만원'), '자 본 금' 이름표 칸엔 값 안 넣음, '총 ○○명'·'□ 주요연혁 / ○' 자리표시, 신인도 서식 '해당 없음'은 첫 열 건너뜀, 따옴표 '해당 없음' 안내만 있어도.
- 자기평가표: '미만' 등급 구간, 원본 '0' 평점 칸 = 빈 칸, 상한이 없으면 항목 괄호 점수, '소계' 줄 아래 평점 칸에도 점수, 배점 열엔 신용등급 글자 안 넣음.
- 화면: '필요 서식' = 번호·이름 목록만(완료 체크·진행도·칩 뺌), 정량평가서 탭도 페이지 스크롤바 하나(iframe 높이 맞춤).
- 대부분 캡처 모양으로 만든 표로 확인 — 원본 서식 파일로는 미확인. 매출액은 여전히 안 채움(회사 자료 없음, 사용자 확인 대기).
