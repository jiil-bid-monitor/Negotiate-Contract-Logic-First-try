## 2. 웹앱 상단 바 알림 (PR #587·#589·#591·#602·#606·#610·#611)

- 계기: 담당자가 웹앱은 매일 보는데 텔레그램은 잘 안 봄. 웹 푸시는 웹앱이 http라 불가(https는 NAS 손볼 때 검토).
- **🔔 회사 서류 N**: 30일 안에 끝나는 서류 + 상태 표시한 지난 서류. 서류 폴더가 보이면 갱신할 서류가 없어도 보임.
  서버 PC 웹앱도 보이게 `COMPANY_DOCS_DIR`·`DOC_STATES_FILE`(NAS 경로) — 서버 PC `.env`에 넣음(사용자, 확인됨).
- **📋 판단할 공고 N**: 텔레그램·메일 보고에 나간 공고 중 판단 안 한 것. 보고 7일 안 + 마감 전 + 사전규격 아님 + **웹앱 실제 공고 탭 목록에 있는 것만**.
  입찰(매일 보고)·협상·규격가격(주간 보고) 두 칸, 칸마다 급한 3건 + '그 밖의 N건'(그 탭 + 참가여부 미지정). 판단하면 숫자가 줄어듦.
- 아이콘에 글자: '📋 판단할 공고 31 · 🔔 회사 서류 5'. 문구 '만료 뒤 N일' → '유효기간 N일 지남'(웹앱·텔레그램).

## 3. 웹앱에서 회사 서류 관리 (PR #592·#593·#594·#597)

- 🔔 창에서 서류 줄에 PDF를 **끌어다 놓거나 골라서** 갱신 → 유효기간은 PDF에서 읽지 않고 늘 고름(사용자 — 잘못 읽으면 엑셀을 다시 고쳐야 해서).
- '전체 서류 관리' 창: 새 서류 추가 · 새 서류 올리기 · 파일 바꾸기(잘못 올린 PDF, 날짜 그대로) · 날짜 수정 · 빼기([이전 서류]로).
- 저장은 텔레그램 `/upload`와 같은 함수(`docupload.save_doc`) — [최신 서류] 파일, 옛 파일은 [이전 서류], 인증서갱신.xlsx·서류목록.xlsx.
- 찾아 고친 문제:
  - 인증서갱신.xlsx 이름('신용평가')과 파일 종류('신용평가등급확인서')가 다른 지일 서류 17종 — 갱신하면 새 종류가 생기고 옛 파일이 남았음 → `file_kind`.
  - 저장 직후 정리가 새 파일을 건너뛰어 옛 파일이 최신으로 남던 것(파일 시각이 '지금'보다 조금 앞섬) → `settle=OURS`. 가끔 실패하던 업로드 시험의 원인.
  - 서류목록.xlsx를 열어 둬 윈도우(서버 PC)에서 다시 못 쓰던 것.
  - 같은 날 같은 서류를 두 번 올리면 두 파일이 다 남던 것, 띄어쓰기만 다른 새 서류 이름 → 기존 서류로.
