# 2026-11-25 작업 기록 (이 세션)

## 1. 그리다 정량평가서
- 대표자 칸 = 등기상 대표(서류 값, 이름·직위·주민번호는 `.env` `QUANT_GRIDA_CEO…`로도). 위임장 '대리인' 칸 = `.env` 지정 임원(`QUANT_GRIDA_AGENT…`, 없으면 예전 `_REP…`).
- **대리인·재직증명서가 늘 비던 진짜 원인**: 공고 이름을 넘겨 만들 때 회사 자료 묶음에서 지정 임원·인력 값이 빠졌음 → 모든 값을 그대로 옮기게 고침(#703). `.env` 문제가 아니었음.
- 재직증명서 = 지정 임원(성명·주민번호·소속·직위·부서·주소·재직기간), 직접 기입 서식이어도 채움. 합치지 않은 '대리인' 머리 칸도 대리인 줄.
- 사용인감계는 그리다 화면에서도 지일 회사 정보(서식 이름에 '사용인감'이 없어도 본문으로 알아봄).
- 기술인력 = 지일 인력. 설립일·사업분야·신용평가·연혁·회사명·주소도 `.env`로. 회사명은 '(주)그리다' 표기(모든 회사).
- 면허/허가/등록증 보유현황 = 보유 자격 파일 등록 업종.
- 실적: `py scripts/grida_tracks.py`가 사업 폴더 문서를 읽어 `공사수주현황_그리다.xlsx`를 만듦(발주기관은 기관 이름만, 금액은 500만 원 이상 중 큰 값). 그리다 실적 표는 발주처 칸을 비움.
- 접수증 제출자 칸은 늘 공란(누가 제출하는지 모름).
- `.env` 읽기가 'KEY = 값'·export·메모장 ANSI 저장 줄도 읽음.

## 2. 정량평가서 규칙 (지일·그리다 같이)
- **고정 규칙: 서명란 '(인)'은 절대 다음 줄로 넘어가지 않음** — 이름 너비를 한글 2칸으로 셈, 모자라면 (인) 뒤·줄 앞 빈칸을 줄임.
- '응모자(대표자)' 묶음 줄의 주민등록번호 = 대표자.
- 자기평가표 경영상태 비고 칸 = 신용평가등급.
- 값 칸에 미리 적힌 작성 안내·예시 글('뒷자리 첫째자리까지 기재' 등)은 지우고 값.
- 입찰보증금 '일금 … 원정(입찰금액의 5%)' 칸, 글자 띄운 '사 업 예 산'도 읽음 — 예전엔 기초금액은 읽었는데 이 모양 칸을 몰라 비었음.
- 정량평가서 화면의 고정 설명 문장 삭제.
