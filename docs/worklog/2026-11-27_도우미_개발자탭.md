## 1. 도우미 (웹앱 오른쪽 아래 웃는 지구)

- **화면엔 꼭 필요한 질문만** — 뺀 질문·사소한 질문(비밀번호·휴대폰·다크 모드 등)은 지우지 않고 채팅으로 물으면 답함(`HELP_CHAT_ONLY`). 비슷한 질문 4쌍 합침.
- **채팅 전용 질문 129개**(탭마다 코드를 읽어 사실 확인), 서버 PC 전용 답은 NAS 답 따로.
- **말투**: 반말·줄임말(어케·어딨·뭐임)·ㅋㅋ/ㅠㅠ·오타 하나(네 글자 이상)·짧은 대답(ㅇㅇ·ㄱㄱ), 탭 이름만 물으면 탭 안내, '○○ 어케 씀' = 그 탭 순서.
  인사·감사·'알겠어'엔 짧게 받음(질문 기록에 안 남김).
- **공고번호로 물으면** 빈 칸은 왜 비었는지(금액 모름·일정 미상 이유) + 가진 정보 전부, '왜?'·'싱크로율은?'처럼 짧게 이어 물으면 방금 본 공고 값.
- **바라는 점 남기기**: '…해 주세요·…했으면' → '개발 담당에게 남길까요?' → 질문 기록에 '요청'. **개발 담당 이름은 화면 어디에도 안 씀**(사용자 지시 — 설정 `HELP_DEVELOPERS`·NAS .env 줄 지움).
- **'어디인지 보기'** 자리를 답에 딱 맞게(카드 마감·금액 칸, 칩, 버튼 — 브라우저로 탭마다 눌러 확인), 같은 제목 질문 버튼엔 탭 이름.
- 시험: 처음 보는 말투 160문장(`casual2`) 첫 결과 85.9% → 97.8%, 실제 질문 기록 세트(`real`). 모든 세트 엉뚱한 답 0(지일·그리다).
- 지일/그리다 화면 차이 질문을 실제 공고 탭 처음 고르기에.
- NAS 도우미 질문 기록(시험으로 쌓인 것)은 사용자 요청으로 지움.
- **투명도 밀대**(창이 공고를 가림): 40~100%, 이 브라우저에 기억, 마우스를 올린 동안은 진하게(밀대를 만질 땐 고른 투명도).
  질문 칸 포커스로 진하게 하는 건 뺌 — 버튼을 누를 때마다 질문 칸이 포커스를 받아 늘 진해짐.

## 3. 개발자 탭 (`?dev=1`)

- **담당자 화면과 비교할 수 있게** 개발자용 내용은 '개발자' 탭 하나에만(예전엔 판단 기록 탭 아래 집계가 붙었음). 한 번 켜면 그 브라우저에서 계속, `?dev=0`으로 끔.
- **대시보드**: 기간(전체·7·30·90일) → 요약 칸 4개 → 판단 기록(주별 막대·사유·수집 경로별·관심 키워드별) → 투찰 분석(월별 결과·기준 − 실제 사정률·웹앱 vs 외주·공고별 표)
  → 도우미 질문(결과별·탭별 + 기록 표). 차트는 직접 그린 SVG(검증한 색, 표로 보기, 커서·키보드에 같은 값).
- **살펴볼 것**: 기준을 넘은 것만 한 줄씩(기준값은 접힌 '기준 보기').
- **자료가 얼마나 쌓였나**: 분석마다 지금 / 권장 건수, 권장 건수의 근거는 접힌 표(사용자 '근거 문장 가독성').
  판단 30건(비율 오차 ±18%p) · 항목마다 10건(윌슨 하한 10/10 = 72%) · 개찰 50건(가운데값 오차 < 0.25%p) · 외주 비교 20건(부호 검정 15/20 p = 0.04) · 도우미 50건(통계 기준 아님).
- **분석하기 = 제안 / 참고**(외부 AI 없음, 판단·투찰 기록을 밖으로 안 보냄): 수집 규칙(판단 10건·윌슨 하한 70%·참가 공고가 안 빠짐), 제외 낱말 후보,
  기준 사정률 폭(업체 목록 있는 개찰을 Δ마다 다시 순위, 30건 이상 + 앞 절반으로 고른 폭이 뒤 절반에서도 나을 때만), 웹앱 vs 외주(부호 검정 20건·p<0.05),
  도우미(같은 말 3번 이상 바로 답 못 함). 항목마다 '숨기기'·'적용 요청'(요청은 질문 기록에). 규칙 반영은 여전히 승인 뒤 PR.
- 실제 자료(NAS, 저녁): 제안 0건. 참고 — 외주 비교 16건 웹앱 13 · 외주 3(p ≈ 0.02, 20건까지 4건), 기준 사정률 +0.25%p는 24건 전체로는 1순위 1 → 2지만 최근 절반에서 나아지지 않음.
- 업체 목록이 NAS에 없던 예전 결과(11/13에 서버 PC에서 넘어온 10건 등 13건)는 다시 받아 채움 — 외주 비교가 6건만 보이던 원인. 앞으로는 밤 작업이 채움.
- **`dev=1`은 주소 어디에 넣어도 켜짐**(서버 PC 사람이 '#live?dev=1'·'?t=…?dev=1'로 넣어 안 켜졌음). '?t=토큰?dev=1'은 예전엔 화면 자체가 안 열렸음.

## 4. 교차 검증 (검토 둘 — 서버 / 화면·도우미)

고친 것:
- 업체 목록 채우기 다시 받기가 실패하면 받아 둔 개찰 결과를 지웠음 → 다음에 '새 결과'로 담당자 방 알림이 또 갈 수 있었음. 이제 예전 결과 그대로, 3번 실패하면 그만.
- NAS 투찰 기록(서버 PC 사본 + NAS 기록)에 결과 칸 바꾸기가 없어 밤 작업이 멈출 수 있었음.
- 기준 사정률 폭 계산이 순공사원가 조건을 안 봐서 무효 금액을 1순위로 셀 수 있었음. 같은 공고 여러 기록은 하나만.
- 도우미가 후보를 보인 뒤 '아니요'라고 하면 답 없이 멈춤(오전 작업에서 생김).
- 주별 판단이 UTC 날짜로 묶여 한국 시각 0~9시 판단이 전날로 감 — 판단 기록 탭 주 묶음도 같은 문제였음.
- 개발자 탭이 10초마다 통째로 다시 그려져 펼친 표가 접힘.
- 도우미가 정상 질문 8가지를 '답 없음'·'요청'으로 보냄(투찰금액 자동 계산·총 사업비·준공 검사원 등) → 낱말을 좁힘, 시험 문제 전부 전후 대조 나빠진 것 0.
- 그 밖: 제외 낱말 비율에 보류 포함, 집계 기준 맞춤, 잠깐 실패하면 받아 둔 기록 그대로, 개발자 탭으로 가면 도우미 창 닫음, 투명도 열 때 번쩍임.

남긴 것: 투명도 밀대를 끄는 중에 도우미 답이 오면 끌기가 끊김(드묾). 도우미 인사 '바라는 점을 적으시면 개발 담당에게 남깁니다'를 남길지 — 사용자 결정 대기.
