# 2026-11-27 — 정량평가서 채우기 · 서명 '(인)' 자리 · 정량평가서 화면 (이 세션)

## 서식 채우기 (#814 무렵~#833, 서버 코드 — 웹앱 다시 켜기)
- '서약자 : OOO회사'만 있는 칸·줄 = 회사명(부산 창의융합교육원 청렴계약 이행서약서).
- 통합서식 잇기 'list index out of range' — 머리말 든 쪽 설정 run 끝을 바르게 찾음, 잇기 실패 시 멈추지 않고 알림 + 서식별 파일(태백 LED전광판).
- '대표자(주민등록번호)' 칸: 첫 줄 이름 + (인), 다음 줄 주민번호(앞 6자리 + 첫 숫자).
- 연혁 표 머리 '연.월.일'(점·가운뎃점·괄호) 알아봄.
- '해당 없음'은 안내가 붙은 표에만(서식 전체 아님), '제안업체의 유동비율' 같은 '…의 ○○' 이름표는 회사 칸 아님(태백 서식 13).
- '총 종사자수' = 종업원 수.
- 그리다 화면 위임장·서약서에 지일 정보 — 안내 문구의 '사용인감계' 낱말로 사용인감계로 봤던 것, 앞 서식 끝 줄바꿈에 붙은 서식 머리를 나눔(운리단길).
- 자기평가표 경영상태: 등급마다 세 줄 합친 점수 칸(운리단길 9-6).
- ':'만 든 좁은 칸(0.3cm) 옆 값은 오른쪽 넓은 칸에(#838 — 글자가 세로로 쌓였음).

## 서명 줄 '(인)' 자리 (사용자 '서식은 건들지 않는다는 고정 규칙 배반' → '재발 보장')
- 가운데 정렬 서명 줄 '(인)'은 원래 자리(그리다 위임장).
- 공통 검사 `fill.seal_moves` + 모양별 시험 묶음 — 서명 규칙을 고칠 때마다 통과해야 함.
- 예전 결정 둘 되돌림: 표 칸 '(인)'은 원래 자리·이름은 그 앞, 서명 줄 아래 '(인)'뿐인 문단은 그대로.
- 어긋나면 알림 대신 원래 자리로(`restore_seals`, 그래도 안 되면 값 글자 줄임).
- 빈칸은 글자 모양 너비만큼만 뺌(14pt 줄 반 글자 어긋남).

## 정량평가서 화면 (#834~#837, 화면만 — F5)
- 기술인력·특허 '모두 체크·모두 해제' 버튼을 표 아래로(위에는 없음).
- 접힌 칸을 펼치면 칸 전체가 보이게 화면을 내림.

## 확인한 것(고치지 않음)
- 참여기술자 보유현황 '분야' 열이 빈 것 = 인력 자료에 분야가 없어 비우는 규칙(11/23) — 사용자 '취소'로 그대로.
